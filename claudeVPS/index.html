توصيات الإنتاج (Production Recommendations)
  • تفعيل ميزة الـ Auto-mute: كتم صوت الميكروفون للمستمعين بمجرد النزول من المسرح لتقليل عدد الـ Active Publishers دائماً.
  • ضبط حدود النظام (Linux ulimit): التأكد من رفع الـ File Descriptors (Open Files Limit) في السيرفر إلى 65535 لدعم آلاف الـ WebSockets المتزامنة.
  • التوسع الأفقي (Clustering): السيرفر الحالي يتحمل حتى 1,500 مستخدم صوتي بكفاءة عالية، وعند الوصول لـ 2,000+ يوزر يمكن إضافة سيرفر آخر وربطهما عبر Redis بدون أي تعديل برمجي على التطبيق.
